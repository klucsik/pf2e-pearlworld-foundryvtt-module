# Pearlworld pf2e foundry module
This foundry module is for the pearlworld written by Klucsik Krisztán Pál, it features new ancestries, extended calendar with Drakonír's 17 months, custom languages and additional lore
For the compendiums to work you must pack them using the foundry extension: https://github.com/foundryvtt/foundryvtt-cli
Once you have downloaded the foundry extension and the module is installed into your foundry use the Makefile to build the compendiums.
```make unpack-all```
